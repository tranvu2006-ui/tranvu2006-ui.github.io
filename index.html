01 / Tóm tắt hồ sơ

Giới thiệu bản thân

Xin chào! Mình là Trần Vũ, sinh viên năm thứ hai chuyên ngành Công nghệ Phần mềm tại Trường Cao Đẳng Công Nghệ Thủ Đức (TDC).

Với đam mê mạnh mẽ trong việc lập trình hệ thống, mình định hướng phát triển bản thân theo con đường Java Spring Boot Fullstack. Mình có kinh nghiệm thiết kế cơ sở dữ liệu quan hệ tối ưu, xây dựng các API Backend bảo mật với Spring Security / JWT và tích hợp với Frontend mượt mà.

Bên cạnh ngôn ngữ Java, mình cũng thành thạo PHP & Laravel Framework để triển khai nhanh các ứng dụng Web đa dạng. Đồng thời, mình còn tìm hiểu lập trình di động bằng Kotlin (Android) để mở rộng tư duy giải pháp công nghệ.

Điểm mạnh & Định hướng

  • Tư duy lập trình hướng đối tượng (OOP) vững
  • Thiết kế & tối ưu hóa RESTful API
  • Quản lý mã nguồn chuyên nghiệp bằng Git/GitHub
  • Kỷ luật, chủ động tự học và chịu được áp lực cao

04 / Đồ án thực hành

Các dự án tiêu biểu

Java // Spring Boot

Hệ Thống Quản Lý Kho Hàng Hóa

Hệ thống Web ứng dụng quản lý kho bãi, nhập xuất tồn kho hàng hóa và nguyên vật liệu. Tích hợp phân quyền Spring Security cho thủ kho và quản lý, kết nối cơ sở dữ liệu quan hệ MySQL thông qua JPA/Hibernate.

  • Thiết kế cấu trúc cơ sở dữ liệu quan hệ MySQL tối ưu hóa chỉ mục (Indexes).
  • Hiện thực hóa cơ chế bảo mật đăng nhập với mã hóa mật khẩu nâng cao.
  • Trình bày giao diện hiển thị dữ liệu động (CRUD) mượt mà kết hợp Thymeleaf.
Java Spring Boot Spring Security MySQL Thymeleaf
PHP // Laravel

Web Quản Lý Kho Hàng Laravel

Ứng dụng quản lý kho hàng hóa và phân tích dashboard số liệu trực quan theo mô hình MVC của Laravel. Tích hợp quản lý phiên đăng nhập, bộ lọc tìm kiếm thông minh.

  • Sử dụng Eloquent ORM để tối ưu truy vấn dữ liệu quan hệ (Eager Loading).
  • Thiết kế Dashboard trực quan tích hợp biểu đồ doanh số xuất nhập bằng Chart.js.
  • Hiện thực hệ thống API RESTful Backend đáp ứng chuẩn dữ liệu JSON.
PHP Laravel 13 MySQL Chart.js Blade Templates
